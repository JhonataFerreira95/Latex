## Como usar

1. Escolha um módulo e consulte seu README para ver os tópicos e exemplos.
2. Abra os arquivos `.tex` em um editor de LaTeX para estudar ou adaptar os exemplos.
3. Compile os arquivos com uma distribuição LaTeX instalada, como MiKTeX ou TeX Live.

Alguns exemplos podem depender de pacotes LaTeX específicos; confira o preâmbulo do arquivo `.tex` antes de compilá-lo.
